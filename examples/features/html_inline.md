Terminals can't render HTML, so the tags are hidden and only the text between them shows.

Attributes go too: <span class="note" title="1 > 0">a span</span>,
a self-closing <br/> and an image tag <img src="logo.png" alt='logo' /> leave no gap.

Comments disappear <!-- like this one --> as well,
even across lines <!-- a comment
on two lines --> like this.

Rarer forms vanish the same way: <?php echo 1; ?><!DOCTYPE html><![CDATA[x < y]]>done.

Not HTML, so literal: a < b > c, <33>, < a>, <a href='x'title=y> and \<b>.
